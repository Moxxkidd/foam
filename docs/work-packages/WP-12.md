状态:pending|依赖:WP-05(可先用 WP-04~08 的成果,不强依赖 11)

## 目标

第二个真实验收,亮出交互会话王牌:对**本地 Metasploitable2 VM**(写入
scope)全程自主拿到 shell:

预期链(同样不给剧本):nmap 全端口/服务识别 → 选择已知弱点
(vsftpd_234_backdoor / distcc / Samba 等,agent 自选)→ 经持久 PTY 驱动
msfconsole(use/set/exploit)→ session 建立 → 执行 `id`/`uname` 取证 →
证据与输出落 loot。

- 环境准备文档:`docs/e2e/scenario2-setup.md`(VM 获取与网络、scope、
  快照建议)。
- 允许重试但如实记录每次失败的形态(msf 提示未识别、session 未建立、
  exploit 失败…)。

## 验收标准

1. agent 自主完成 use→set→exploit→session 全程,无人触碰键盘。
2. `id`/`uname` 输出在 loot,证据路径可核;审计链 verify 通过。
3. msfconsole 会话的结构化提示识别在真实 run 中生效(日志引用事件)。
4. 如实记录:尝试次数、失败形态分类、provider 审核事件、耗时。
5. 未达标项不得隐瞒。
