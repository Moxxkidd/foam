# WP-08:工具地图(全库盘点 → prompt 注入)

状态:pending|依赖:WP-04

## 目标

兑现「整个 Kali 库」承诺:LLM 从**本机实装全库**选工具,不是从白名单选。

- 内置工具目录(仓库内静态数据):覆盖 Kali 主要 metapackage 的 100+
  常用工具,按渗透阶段分组(信息收集/漏洞分析/Web/密码/嗅探逆向/
  后利用/报告),每个工具一句话用途 + 常用 flag 提示。
- `toolmap.py`:启动时盘点——`shutil.which` + 常见安装路径探测 +
  `dpkg -l` 对照,产出"本机可用"子集;缺失的标注未安装(LLM 可决定
  `apt install`,该命令同样过 scope/审计)。
- 生成紧凑的工具地图文本,注入 WP-04 system prompt 的预留注入点;
  体量预算 ≤2KB(超了按阶段裁剪,当前阶段相关组优先)。
- `kalicode run` 启动日志显示盘点结果(可用/缺失计数)。

## 排除项

- 工具自动安装策略(只标缺失,不自动装)。
- 工具用法深度教学(一句话为止;深度靠 LLM 自己 `man`/`--help`,
  这正是 bash 全开的意义)。

## 涉及文件(本 WP 拥有)

- `src/kalicode/agent/toolmap.py`
- `src/kalicode/agent/tool_catalog.py`(静态目录数据)
- `tests/test_toolmap.py`

## 验收标准

1. 目录数据完整性单测:分组齐全、每条有句用途、无拼写死链(工具名
   与 which 探测键一致)。
2. 盘点器单测:fake PATH/假 dpkg 输出下的可用/缺失判定。
3. 注入单测:地图文本 ≤2KB、包含当前实装工具、不含品牌名。
4. Kali 实测:真实 Kali 环境跑一次盘点,覆盖率(目录中实装比例)记录
   进开发日志。
