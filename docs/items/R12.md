### 2026-11-04 实施评审（通过，条目进入进行中）

评审基线为 `2c588a6`（main == origin/main）。已直接核对 R03 的
`AgentLoop._finish`/`runtime.close_run` 与 R09 的 `write_manifest` 实现及真实
验收记录，不依赖“完成”标签。当前代码证实四项缺口：`Usage()` 缺省为 0；
失败/取消的重试尝试没有统一落账；压缩后的 `still_over_budget` 不阻止下一
请求；新 `AgentLoop` 的轮数/token 从零开始且连续对话会重置段内轮数。

冻结以下实现口径：

1. 新增 `agent/budget.py` 作为唯一总账模块。每次请求以本地 `request_id`
   关联 `phase=main|scope_compile`、provider、attempt、完成状态和
   `measurement_status=measured|estimated|unknown`；实测与估算分列，任一
   必需字段缺失即保留 unknown，不再转换为 0。失败、取消和修正重编译也
   各记一笔；主环成功请求与重试尝试不得重复记账。
2. 总账覆盖编译、主环、重试、连续对话和 resume。`run_started` 写 opening
   快照，`run_finished` 写 closing 快照；恢复以最新 opening 为锚并重放其后
   新用量，旧链无快照时按可识别字段重建且未知项不置零。TUI 预声明/run 前
   编译经同一内存账本结转到正式 run 的 opening 快照。墙钟历史只存 UTC
   秒数，当前段使用 monotonic；崩溃造成的不完整历史段标 unknown，不把离线
   间隔算作运行时长。
3. 限额维度为 context、累计 tokens、累计 rounds、wall_time；新增
   `--max-total-tokens` 与 `--max-wall-time`（秒）。resume 缺省继承链上最近
   限额，显式变化写 `budget_limit_changed`（operator、前后上限、expanded/
   tightened）。`max_rounds` 改为累计口径，普通插话和 resume 均不重置。
4. 每次模型派发前检查压缩后的 context 与总账；工具派发前再查。达到边界
   停止新派发，已在途响应允许完成并记录超额；若响应无需后续派发可正常
   结束。有限累计 token 下出现 unknown/不足以证明未超限的用量时，停止后续
   派发而不是按 0 放行。接近限额只给一次收尾引导，不自动扩容。
5. 预算停止使用 `RunResult.status="stopped"`，审计另记 stop_reason 与
   `goal_status="unfinished"`；不调用 `mark_closed`，CLI/TUI 退出码按失败
   处理，仍经 `_finish` → `close_run` → `write_manifest`。恢复须显式提高
   相关上限；TUI `/budget` 仅作显式变更和展示，普通文本永远只是插话。
   本版本不新增 TUI 进程内重建已关闭 runtime 的通道，停止后由 CLI resume
   恢复。
6. OpenAI `finish_reason=length`、Claude `stop_reason=max_tokens` 进入
   非重试 incomplete/error；缺失 `[DONE]`/`message_stop` 的截断流进入
   可重试 StreamError。部分响应用量仍先落账，不作为完成摘要。
7. 无本地定价表，`estimated_cost` 恒为 None/unknown；不实现精确美元硬上限。
   不修改 scope 判定、授权规则或进程隔离语义，不新增依赖、数据库字段或
   engagement 布局。

接口漂移：除规格候选文件外需改 `backends/openai_compat.py`、`claude.py`、
`runtime.py`/`evidence.py` 的纯增量展示或终态字段，以及 `tui/widgets.py` 的
预算文本（如实际展示需要）；`state/files.py` 和 `state/index.py` 不改。
扩展现有测试文件，不新增平行运行时/证据模块。无待用户裁定的重大取舍。
