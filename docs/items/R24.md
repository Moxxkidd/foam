## 2. 依赖、架构与数据契约

前置依赖：[R08](R08.md)、[R09](R09.md)、[R17](R17.md)

静态导出与可选 viewer 共用只读报告模型。导出模式显式为 redacted/internal，默认分享为 redacted；模板只接收已转义字段。viewer 若启用只绑定回环地址，使用随机会话凭据，不接受任意文件路径。

技术栈：Python/asyncio，沿用仓库 SQLite、PTY、Textual 与后端协议；新增模块仅在下述职责确有需要时建立。

### 全局约束

- Python ≥3.12、asyncio；标准库优先，新增依赖须说明理由，不引入重型框架。
- 仅服务明确授权目标；不为测试放宽 scope；API 密钥只走环境变量，fixture 使用 example.com/TESTONLY 等明显合成值。
- 运行产物与真实凭据不提交；历史审计链不重写；旧字段未知不等于零或已验证。
- 本文是规格与实施计划草案；用户此次授权编写文档，不代表授权所有功能实施。
- 后续按 AGENTS.md §7 一次推进一个条目/独立分片；使用 executing-plans 逐步执行，未决授权语义先裁定。
