## 1. 问题、目标与边界

来源：[路线图](../roadmap/2026-09-25-release-roadmap.md)、[评估报告](../reviews/2026-09-25-repository-and-ux-assessment.md)。
评估代码基线：`3a9d07c7da9130e99681a48b5c8975b84b511492`。历史复现是设计输入，不作为本条目已修复证据。

- **来源与依赖**：E04；依赖 R02 的运行状态约定。
- **交付**：CLI/TUI 共享资源所有权，bash 与 session 有幂等关闭路径；finished/error/kill/cancel 均停止新调度、清理本 run 进程、收割输出、落终态；异常期间也释放索引和后端连接。
- **范围/候选文件**：`src/foam/tools/bash.py`、`src/foam/tools/session.py`、`src/foam/agent/loop.py`、`src/foam/cli.py`、`src/foam/tui/app.py`；新增 `src/foam/runtime.py` 仅在职责收口有必要时采用；tests/test_bash.py、test_session.py、test_loop.py、test_cli.py、test_tui.py。
- **排除**：不杀同机其他用户或不属于本 run 的进程；不新增无监督 daemon 模式。
- **风险与回退**：原提示“进程只会被 timeout/kill_job 终止”需随新生命周期契约更新；active 待命期间不自动结束资源，只有真实 run 退出才收口。避免先关审计后清理而丢失终态记录。

## 2. 依赖、架构与数据契约

前置依赖：[R02](R02.md)

拟议统一关闭入口接受 run_id 与 reason，返回 cleanup_status、remaining_resources、errors。顺序固定为停止派发→终止/收割本 run 资源→收集输出与终态→关闭索引/审计/后端。SessionTool.aclose 复用，BashTool 补齐同等幂等关闭能力。

技术栈：Python/asyncio，沿用仓库 SQLite、PTY、Textual 与后端协议；新增模块仅在下述职责确有需要时建立。

### 评审记录（2026-10-06，实施评审与契约核对）

评审结论：**通过实施评审门**。当前状态代码双重映射结论与规格 §1 问题
陈述一致（E04 复现路径、CLI 审计倒挂、kill 路径逐个 5s、前台取消带走
看管、session aclose 强标 closed、TUI StateTool 索引泄漏、file 流锁拒绝
路径 backend 泄漏，均逐一确认后开工）。以下决策冻结：

- **D1 宽限期：无**。run 终止（finished/error/kill/外部取消）即以
  SIGKILL 收割残留进程，与既有 kill_job/timeout 语义一致（run 结束时
  残留的 job 按定义已无人看管）。上界显式可测：
  `CLOSE_REAP_TIMEOUT_SECONDS = 5.0`（bash/session 各自单层上界，
  常量被测试钉死并可经 monkeypatch 收紧实测）;close_run 收割阶段总
  上界 = 两层之和，文档化于 runtime.py 模块 docstring。R18 的 UI 不得
  改写本语义。
- **D2 cleanup_pending 面**。审计终态记录（run_finished，kill 路径另有
  kill_switch）携带 `cleanup` 载荷（cleanup_status/remaining_resources/
  errors,含分层子报告）——kind 不变、payload 键纯增量，replay.py 只读
  既定键故零改动；CLI 清理失败打 stderr `[cleanup_pending]` 行、TUI 上
  叙述流 error 通知（文本共用 `runtime.cleanup_warning_text`);**退出码
  契约不变**(0/130/1/2);engagement.json schema 不变。
- **D3 TUI 单写者锁：不接**（R02 文档化边界维持）;close_run 的
  `lock=None` 分支即为此设。
- **D4 TUI finished → mark_closed**（与 CLI 对齐）;killed/error 保持
  active(R02 边界不变）。
- **D5 审计封口顺序统一**：收割 → 终态记录 → 关 state 索引 → 关
  engagement（含其懒加载索引）→ **审计最后** → 关后端 → 放锁。修复
