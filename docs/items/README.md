## 使用方式

1. 从版本清单选择一个条目，读取其依赖与评审门。
2. 依赖接口落地后复核规格；按授权范围评审、实现和验证，一次一个条目/分片。
3. 在 R 文档保存验收证据，在版本清单更新状态；版本发布再做跨条目用户旅程验证。

代码基线是 `3a9d07c7da9130e99681a48b5c8975b84b511492`；后续文件位置和接口可能变化，实施前须核对。
