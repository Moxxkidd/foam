### 实施评审定案（2026-10-06，E05 代码复核 + 决策 D1–D6）

**E05 现状复核确认**：`replay.py:457` 以 `limit=10000` 请求六表、只读
`["rows"]`（被 `index.py:374` 的 `MAX_QUERY_LIMIT=500` 钳到 500，
total/count/truncated 被忽略），统计用同一批被截断列表的 `len()`——
501 行起正文与统计同时静默漏项，红基线实测复现（§6）。修复对公共契约
纯叠加：`Index.query` 签名/返回字段、MAX_QUERY_LIMIT、LLM 侧
`state_query` 500 上限、报告章节结构均未变。

**ORDER BY 不稳发现（必须先修，否则 AC02 不可能）**：原 `_order_by`
六表中五表存在非确定并列（ports 同端口 tcp/udp、creds 同用户不同
secret、vulns 同 kind 不同标题、loot/notes 秒级 ts 并列），OFFSET/LIMIT
分页跨页可能重/漏行。

- **D1**：`_order_by` 各表末尾追加 `t.id` 兜底，并列时排序确定。仅影响
  并列行相对顺序，无字段/签名变化；`test_query_pagination`（唯一 ip）
  不受影响（实测全绿）。
- **D2**：报告快照 = 报告专用连接上的新增纯叠加接口 `Index.snapshot()`
  显式只读事务（BEGIN … COMMIT/ROLLBACK；该连接事务期间
  isolation_level=None，退出恢复）。rollback-journal 模式下并发写者的
  COMMIT 拿不到 EXCLUSIVE：**实测修正一处预期——pysqlite 连接默认
  `timeout=5.0` 装了 busy 重试器，写者不是“立即” SQLITE_BUSY，而是 busy
  重试耗尽（≤timeout）后以 `OperationalError: database is locked` 失败；
  若快照很短，写者也可能只被延迟到快照结束后提交成功。两种结果下报告
  读到的都是同一快照，均满足 AC04「一致读快照或明确拒绝」**。写者侧
  行为注记（WP-06 写路径须知）：报告快照期间，常驻写者（StateTool/
  Engagement.index）的业务 COMMIT 可能阻塞至 timeout 后抛
  OperationalError——属明确拒绝而非损坏，ROLLBACK 瞬时（不碰 db 文件），
  快照结束后写入恢复；同期新建 `Index()` 的 DDL/元信息 commit 同样被拒。
  不启用 WAL（库级持久变更，另行决策，正确性不需要）。
  `Index.__init__` 的 DDL/元信息写入发生在进入快照之前，不属于快照内容。
- **D2 附带加固（测试实测发现）**：`Index.__init__` 的初始化 commit 被
  拒时原实现泄漏打开的连接——异常 traceback 帧持引用使连接存活，其
  RESERVED 锁会把快照后的写者阻塞到 busy 超时（实测 5.4s 后
  "database is locked"）。现 `__init__` 失败路径显式关闭连接，不留僵尸；
  回归 `test_index_init_refused_during_snapshot_leaves_no_zombie`。
  同片为 `Index.__init__` 增加 keyword-only `timeout` 透传
  （默认 5.0 = sqlite3 默认，行为不变；供测试提速与未来写者锁策略）。
- **D3**：正文与统计同一快照同源——每 kind 分页遍历（请求 limit=500，
  **按结果实际 count 推进 offset**，而非请求值——钳制下按请求值推进会
  跨不过被钳窗口）；空页但 total 未耗尽 → `ReportGenerationError` 明确
  报错（防 `offset += len(rows)` 型死循环与静默截断）；各页 total 恒定
  校验（变化即快照语义被破坏，拒绝）。统计取分页结果的 total，不再用
  `len(被截断列表)`；未启用 `Index.counts()`（另一连接语句会破坏单源）。
- **D4**：`build_report` 失败（空页错误等一切异常）→ `_cmd_report`
  捕获 → stderr + rc 1，目标文件不动（此前异常未捕获直接抛栈）；写盘
  OSError → stderr + rc 2（既有约定保留，缺目录仍归 rc 2——mkstemp
  即抛）；「[report] 已写入」只在原子替换成功之后打印。
- **D5**：原子导出 = `tempfile.mkstemp`（同目录、唯一名）+ 写完后
  `os.replace`；任何失败清理临时文件；先生成完整文本再替换（既有形态
  保留）。未复用 `files.py._atomic_write_text`（固定名 .tmp 且失败不
