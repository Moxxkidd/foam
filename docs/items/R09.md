## 1. 问题、目标与边界

来源：[路线图](../roadmap/2026-09-25-release-roadmap.md)、[评估报告](../reviews/2026-09-25-repository-and-ux-assessment.md)。
评估代码基线：`3a9d07c7da9130e99681a48b5c8975b84b511492`。历史复现是设计输入，不作为本条目已修复证据。

- **来源与依赖**：旧维护批 2/3、loot 快照语义；依赖 R04/R06–R08。
- **交付**：建议新增 `foam verify <dir>`；分别输出审计链、产物 hash、证据引用、终态/覆盖的核验状态；loot 记录登记时快照与最终核验时快照；任务终态生成确定性的证据摘要页，不依赖额外 LLM 才能保全结果。
- **范围/候选文件**：`src/foam/guard/audit.py`、`src/foam/tools/output.py`、`src/foam/state/index.py`、`src/foam/replay.py`、`src/foam/cli.py`；可新增 `src/foam/evidence.py` 收口清单生成与验证。
- **排除**：不声称本地 hash 链具有外部不可抵赖性；不恢复从未记录的旧会话输入。
- **退出码建议**：0=所请求检查均通过且无未知项，1=已确认不一致，2=输入/使用错误，3=证据不足或运行未完成；不更改现有 run/replay 退出码。最终取值在规格中冻结。
- **风险与回退**：manifest 必须绑定 scope 修订、run ID 和结束原因。外部锚点作为未来独立选项；本版本始终显示未外部锚定。

**退出码冻结**（规格 §17 建议原样冻结）：`0`=所请求检查均通过且无未知项；`1`=已确认不一致（任一维度 fail）；`2`=输入/使用错误（目录不存在/非 engagement 等）；`3`=证据不足或运行未完成（无 fail 但存在 unknown/pending）。混合结果 fail 优先于 unknown/pending。cli.py 新增常量 `EXIT_UNKNOWN=3`；run/resume/replay/report/tui 既有退出码（0/1/2/130）不变。

**决策 1–10**（实施依据；与代码事实冲突时以代码事实为准并记偏差）：

1. 退出码如上冻结。
2. 新模块 `src/foam/evidence.py` 收口两类职责：`build_manifest(...) -> dict | None`（确定性：数组排序、`json sort_keys`、`generated_at` 注入；无 run_finished 返回 None——无终态不补造）与 `verify_engagement(root) -> VerifyResult`（chain/files/references/coverage 四维，每维 status ∈ pass/fail/unknown/pending + 定位明细；人读渲染与 JSON 渲染共用同一 VerifyResult 对象，AC07 一致性由构造保证）。
3. manifest 绑定与生成挂点：run 终态（finished/killed/error/cancelled 四种都算）在 `close_run` **之后**从纯读源构建（审计链文件 + `mode=ro` SQLite + engagement.json），不干扰 R03 关闭序、不改 audit/index 既有字节；写入 `evidence/manifest-<run_id>.json`（机读）与 `evidence/summary-<run_id>.md`（结项页，同一 manifest dict 渲染），文件 0600。接线：cli.py `_drive` finally 内 close_run 后 + tui/app.py `_run_to_end` 收尾同构；manifest 生成失败不反转 run 退出码，stderr/叙述流警告如实上报。崩溃无 manifest → verify 显示 unknown/legacy（AC03），不补造。manifest 绑定**终末 run**（链上最后一条 run_finished 的 run_id/status/error；killed 附最近 kill_switch 理由），产物清单盘点**全 engagement**（job_events 全部行 + exec_result_meta + session 转录目录扫描 + loot 行，每项 rel path/sha256/size/source/ref_id/hash_origin；session 项标注 manifest 时点快照——无登记 hash 属已知缺口），另含 loot_snapshots（登记 sha256/size/ts vs manifest 时点值分列）、evidence_refs 清单、pending 计数、`external_anchor="none"`。
4. **schema v4**：loot 增 `sha256 TEXT`（可空，旧行 NULL=unknown）。state_add_loot 经 R08 helper 同一次 open/fstat 流式算出登记时 hash 入库；重复登记保留**首次**登记 hash 不覆盖（`COALESCE(loot.sha256, excluded.sha256)`——登记时快照不可覆盖，旧 NULL 行允许升级为有快照；kind/note/size_bytes 既有更新语义不变，测试钉死差异）；索引层迁移沿用 PRAGMA 探测+单事务 ALTER+一次性备份（备份命名按版本标记，`.pre-v4.bak`）。v3 程序写 v4 库反向兼容测试照 v2→v3 模板。
5. **verify 只读实现**：`EngagementPaths` 纯实例化 + `sqlite3.connect(f"file:{db}?mode=ro", uri=True)`（无 journal/无迁移/无 chmod；schema 能力经 PRAGMA table_info 探测，缺表/缺列的来源维度报 unknown 并标注 legacy）；不取锁；不创建任何文件；不执行旧命令；不跟随目录外引用。AC04 测试：完整目录前后文件清单+内容 hash+stat 元数据快照对比（st_mode/st_mtime/st_ctime/st_size/st_ino 逐项不变，无 journal/wal/bak/lock/evidence 新增）。**实现注记**：st_atime 不在对比面——内容核验必须读文件，读即可能更新 atime（relatime），属核验语义固有，其余元数据逐项钉死。
6. 四维语义：
   - **chain**：audit `explain` + `find_chain_break` 定位；pass/fail；audit.jsonl 缺失而目录是 engagement → fail（定位）；目录非 engagement（engagement.json 与 audit.jsonl 均缺）→ rc 2。
   - **files**：遍历有记录产物（链 exec_result_meta、job_events output_refs、manifest artifacts、loot 登记 hash）逐一重算 sha256 对照——删除/修改分别定位（AC01）；无登记 hash（旧 loot 行）→ unknown；仍在写入信号（链尾 run_started 无配对 run_finished）→ pending 兜底（AC02；不试取锁，只用链与 meta 信号）；盘上存在但无任何记录的文件（outputs//loot/ 扫描）列出计 unknown（不 fail）。
   - **references**：evidence_refs 逐条——界内相对路径查存在性（缺失 fail 定位、存在 pass；不核验内容，无登记 hash 可对照）；界外/绝对路径不打开不跟随，标 unknown 并逐条定位列出（逃逸引用可定位但不判罚——解析器界外 provenance 属已知合法形态，如 sqlmap CSV，见 R08.md §8 (h)）。
   - **coverage**：run 配对（未配对 run_started → pending）、job_events pending 行计数、session_coverage legacy/tracked、终末 run manifest 缺失 → unknown/legacy（AC03）、`external_anchor` 恒显示「未外部锚定（本地哈希链仅供篡改检测，截尾/整体重写不可检测，不构成外部不可抵赖）」。
7. **CLI**：`foam verify <dir> [--json]`；人读默认 stdout、错误 stderr、`--json` 时 JSON 上 stdout。`load_dotenv` 的 `[config] .env 注入…` 注记对 verify 改走 stderr（消除 JSON 污染源；实现选择记录于此——仅 verify 改道，其余命令输出形态不变）。`test_help_all_subcommands` 名单加 verify。
8. **结项页人读形态**：`summary-<run_id>.md` 从 manifest dict 确定性渲染（同 generated_at 逐字节一致）；内容节：终态（status/error/kill 理由）/范围哈希/链头/产物清单与 hash/loot 快照对照/pending 项/外部锚定声明。run 结束时 CLI stdout 打印摘要要点（数行，不刷屏）；TUI 叙述流给结项通知。R18 复用摘要是未来条目，本条目只保证数据结构稳定。
9. **范围外边界**：不声称外部不可抵赖（截尾/整体重写不可检测，输出中明示）；session 转录无登记时 hash（manifest 时点快照替代，口径标注）；旧 run 无 manifest 不补造；verify 不核验 evidence_refs 的文件内容（无登记 hash，只查存在性/界内）；TUI idle 待命期不产生 manifest（run 未终态）；atime 变化不属「改动被检查数据」（见决策 5 注记）。
