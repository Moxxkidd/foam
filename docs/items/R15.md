## 1. 问题、目标与边界

来源：[路线图](../roadmap/2026-09-25-release-roadmap.md)、[评估报告](../reviews/2026-09-25-repository-and-ux-assessment.md)。
评估代码基线：`3a9d07c7da9130e99681a48b5c8975b84b511492`。历史复现是设计输入，不作为本条目已修复证据。

- **依赖**：R02/R03/R09/R13/R28。
- **交付**：TUI 可选择新建、查看最近任务、只读打开结果或恢复；展示目标、护栏模式（`target_only` / `scope_guard`）与当前 scope、状态和最后活动；恢复前做完整 preflight。明确 `--workdir` 是准确目录，父目录需求使用独立参数，并给旧 TUI 用法迁移提示。
- **范围/候选文件**：`src/foam/tui/app.py`、拟新增 `tui/screens/tasks.py`、`src/foam/cli.py`、`src/foam/state/files.py`；可新增轻量任务目录发现模块。
- **风险与排除**：不做跨机器同步或多用户权限系统；复用后端及恢复服务，不复制第三套装配逻辑。

## 2. 依赖、架构与数据契约

前置依赖：[R02](R02.md)、[R03](R03.md)、[R09](R09.md)、[R13](R13.md)、[R28](R28.md)

任务摘要直接复用 R13 的只读 status 结果（run_state、liveness、最近活动、预算快照等），不另写读取器或活性判定；列表读取不实例化会创建文件的运行对象。新建、只读打开、恢复是三种不同动作，恢复走 R02 preflight 和单写者保护。

技术栈：Python/asyncio，沿用仓库 SQLite、PTY、Textual 与后端协议；新增模块仅在下述职责确有需要时建立。
