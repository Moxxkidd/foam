## 1. 问题、目标与边界

来源：[路线图](../roadmap/2026-09-25-release-roadmap.md)、[评估报告](../reviews/2026-09-25-repository-and-ux-assessment.md)。
评估代码基线：`3a9d07c7da9130e99681a48b5c8975b84b511492`。历史复现是设计输入，不作为本条目已修复证据。

- **来源与依赖**：R10 的经评审方案，R02/R03；不得跳过研究门。
- **交付**：将 bash、PTY 及其后代置于受保护执行环境，控制面/LLM 通道独立；工具进程不继承模型 API 密钥，不可访问管理套接字/修改规则；规则安装失败拒绝启动受保护 run。限制目标侧进程可修改的控制元数据，审计以控制面事件为准。
- **范围/候选文件**：拟新增 `src/foam/guard/network.py` 和最小执行适配器；`runtime.py`（如 R03 已引入）、bash/session/CLI/TUI 接线；Linux 集成与权限边界测试。
- **兼容与排除**：本版本给出已验证的 Linux 受保护配置，保留传统运行路径时必须显式标注其能力；没有自动 fallback。URL 路径、通配域与远端二次执行按 R10 矩阵拒绝或声明不具完整强制能力，禁止泛称全覆盖。
- **风险与发布门**：涉及 root/helper 权限和工具 capability，属于最高验证成本项。未获实机证据就不发布“受保护执行”特性，可继续独立发布维护补丁。
