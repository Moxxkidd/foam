## 1. 问题、目标与边界

来源：[路线图](../roadmap/2026-09-25-release-roadmap.md)、[评估报告](../reviews/2026-09-25-repository-and-ux-assessment.md)。
评估代码基线：`3a9d07c7da9130e99681a48b5c8975b84b511492`。历史复现是设计输入，不作为本条目已修复证据。

- **来源与依赖**：旧维护批 1、known-issues ④⑤；依赖 R03/R06 的资源/事件约定。
- **交付**：open/send/read/close/list 的调用、结果或失败可关联 session ID；提示类型与转录 offset 落盘；replay/统计能看懂交互阶段。高频轮询允许可核验聚合，不能伪造一条等于一次操作。
- **范围/候选文件**：`src/foam/tools/session.py`、`src/foam/agent/loop.py`、`src/foam/guard/audit.py`、`src/foam/replay.py`、`src/foam/tui/bridge.py`；相应测试。
- **排除**：不把口令输入或所有转录复制进审计链；不将审计补齐表述为 PTY 授权检查已解决。
- **风险与回退**：短口令的裸 hash 也可能易猜；敏感输入优先只记“发生输入”等元信息，不把 hash 当作加密。原始转录作为独立敏感产物管理。

## 2. 依赖、架构与数据契约

前置依赖：[R03](R03.md)、[R06](R06.md)

拟议事件关联 run_id/session_id/call_id；prompt 事件含 pattern_kind 与 transcript_offset。调用结果与取消独立可见。敏感输入只记类型、发生时间等元信息，不写口令原文或可穷举的裸 hash。

技术栈：Python/asyncio，沿用仓库 SQLite、PTY、Textual 与后端协议；新增模块仅在下述职责确有需要时建立。

### 全局约束

- Python ≥3.12、asyncio；标准库优先，新增依赖须说明理由，不引入重型框架。
- 仅服务明确授权目标；不为测试放宽 scope；API 密钥只走环境变量，fixture 使用 example.com/TESTONLY 等明显合成值。
- 运行产物与真实凭据不提交；历史审计链不重写；旧字段未知不等于零或已验证。
- 本文是规格与实施计划草案；用户此次授权编写文档，不代表授权所有功能实施。
- 后续按 AGENTS.md §7 一次推进一个条目/独立分片；使用 executing-plans 逐步执行，未决授权语义先裁定。
