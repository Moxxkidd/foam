自查素材:pilot 驱动 TuiApp 跑完整流程(呼号门 → 三轮 run:思考×2、

并逐格重建字符矩阵核对(排除渲染器伪影)。基准:strix(渗透 TUI,
海报式开屏 + 工具面板流)与 Claude Code(极简,无开屏,提示符+状态行)。

cyan `#56d4dd` → blue `#58a6ff` 渐变——对齐 strix 的海报仪式感,但字
形由 `__app_name__` 实时渲染,不是贴死的 figlet,改名零返工)→ 版本
号(dim)→ `后端 provider · model` 一行 → `scope 路径 · N 条规则 ·
sha256:前12` 一行 → 黄色双行红线「仅服务明确授权目标 · 每条命令过
scope 护栏 / 全程哈希链审计」→ 呼号输入框(42 列,聚焦 cyan 边框,
placeholder 示例)→ dim 提示 `Enter 进入 · Ctrl-Q 退出`。对比:信息

## 设计取舍

1. **observer 无渲染状态,渲染状态全在主界面**(bridge.py):TuiObserver
   把 loop 钩子逐条翻译成 textual Message 投递,主界面按到达顺序归约。
   契约测试因此可以绕过 loop 直接投递消息,loop 也不知道 TUI 存在。
2. **工具卡紧凑流 + 异常自展开**(定案 Q2):运行/完成各一行,Enter/
   点击展开;护栏拒绝(GuardMsg 先到置 `force_expand`)、非零退出、
   error、超时、被杀、会话待输入六类自动展开——「安静时一行,出事
   摊开」。
3. **阶段 = 模型负责制的字段,不是 UI 推断**(Q3):loop 每轮读
   ENGAGEMENT.md 抽「最近/当前阶段」字段(最后一个出现为准,容忍
   `#`/`-`/加粗/全角冒号变体),变化才发 `on_phase`;TUI 只渲染。
   没有工具→阶段映射表,没有 [PHASE] 标记语法。
4. **思考审计哈希-only**(Q6):ReasoningDelta 只进界面与
   `llm_exchange_meta` 的 sha256+chars;对照组测试保证无思考的轮次
   不出现 reasoning_* 字段。
5. **呼号三去向**(D1):engagement.json `operator` 字段 +
   operator_interject 审计载荷 + `~/.foam/config.json`(0600,合并写
   保其他键)下次预填。空呼号拒入——审计身份不可匿名。
6. **双通道控制面**(Q4):普通文本=插话(队列,turn 边界注入);
   `/` 七命令带补全;Ctrl-X/Ctrl-C kill(二次确认,5s 武装窗)、
   Ctrl-P 暂停/继续、F2 侧栏。**不做 `!` shell 前缀**(红线:绕护栏、
   破审计)。
7. **装配与 WP-10 同构**:默认 factory 挂 exec/会话/状态三组工具 +
   工具地图进 prompt,`RunHandle.sessions` 供侧栏与退出清理;
   `loop_factory` 钩子留给自定义装配,本包不再被别人改。
8. **侧栏轮询容错**:2s 轮询 jobs/sessions/索引/预算,任一数据源异
   常保留上次好值,绝不炸叙述流。

## textual 踩坑(本仓首次大规模用,留给后人)

1. **自死锁**:`await switch_screen()` 写在被换下屏幕自己的消息处理
   器里,拆除屏幕要等其泵跑完当前消息、当前消息又在等换屏——实测
   挂死。解法:`self.app.run_worker(...)` 异步发起。
2. **`Widget.name` 是只读 property**(DOMNode):自定义组件赋
   `self.name` 直接 AttributeError。ToolCard 的命令名改用 `tool_name`。
3. **`MessagePump._running` 是框架字段**:我自定义的「卡片在跑」标
   志同名,挂载时被框架覆写回 True,出现「finalize 先于 mount 完成
   则 spinner 永转」。改名 `_spinning`;并对 `_spin` 加滞留帧守卫
   (timer stop 后队列里最后一帧不得盖回 spinner 头)。
4. **`Widget._render()` 是框架内部方法**:我起的「重绘」助手同名,
   返回值 None 被框架当 Visual 用,渲染期 `AttributeError:
   'NoneType' object has no attribute 'render_strips'`。改名 `_redraw`。
   教训:**自定义组件状态/方法命名前先 grep textual 源码**。
5. **快捷键遮蔽**:焦点在 Input 时,textual 默认把 ctrl+x/ctrl+c 绑给
   cut/copy,App 把 ctrl+p 绑给命令面板——kill/暂停是安全控制面,
   必须 `Binding(..., priority=True)` 压过编辑类绑定(编辑功能让位),
   并 `ENABLE_COMMAND_PALETTE = False`。
6. **`app.query_one` 只查默认 screen**:push/switch 之后要持有屏幕实
   例直接查(`self._main`),或 `app.screen`。
7. **mount 是异步的**:消息处理器里 mount 完立刻 feed/finalize 会打
   到未就绪子节点。可交互组件一律「状态先进内存、`on_mount` 置
   `_ready` 后才落 DOM」。
8. **`ListView.clear()/extend()` 返回 AwaitComplete**:不 await 则
   `index` 高亮落空(快速连打时补全弹层闪烁)。
9. **Static 取内容用 `.content`**(8.x 已无 `.renderable`);模型文本
   一律 `Static(markup=False)`,方括号等内容不得被当 console 标记。
10. **样式串里 `rgb()` 不能带空格**:渐变插值直接用 `#rrggbb`。
11. **`Input.Changed` 对程序化赋值同样触发**:接受补全设值后会再走
    一遍 on_changed——「已是完整命令」要在弹层逻辑里显式收起,否则
    弹层回弹。
