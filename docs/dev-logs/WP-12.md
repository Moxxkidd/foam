## 踩坑

1. **ms2 镜像必须 `-dit`,裸 `-d` 假死**:镜像 CMD 为
   `sh -c "/bin/services.sh && bash"`——服务脚本跑完 exec 交互式
   bash;无 TTY/STDIN 时 bash 立刻退出,容器 `Exited (0)` 假死(日志里
   服务明明全起来了)。第一轮因此拿到 `Exited` 容器与空 IP 的 scope
   (写成裸 `/32`),重新 `-dit` 起容器后重生成 scope 才过探针。已收
   HANDOVER 陷阱 22。
2. **docker CLI 对无响应 daemon 无限阻塞**(Mac 开发机实测,probe 首版
   卡死):自动化里一律给上界(`timeout 15 docker`,Kali coreutils 自带;
   macOS 无 timeout(1),探针做了有无分支)。同收陷阱 22。
3. **zsh 非交互 SSH 远端命令也 source `~/.zshenv`**——LLM env 的正确
   落点是 zshenv 而非 bashrc;首次回填时文件被硬折行,孤儿的
   `export ` 行在 source 时打印全部导出变量(污染 SSH 输出),带前导
   空格的 `  FOAM_LLM_MODEL=` 静默不生效。行号手术修复(保留 key 行
   原文、全程未打印 key 值)后探针 env 三项转绿。已收 HANDOVER 陷阱 23。
4. **协调层 rsync/zsh 两事故**(openrsync 缺省目标=cwd 配 `--delete`
   会删家目录;zsh 赋值语句里冒号后 `~` 被本地展开)——先于本 WP 实弹
   发生,已即收录 HANDOVER 陷阱 21,此处不再展开。
