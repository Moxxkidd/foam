## 设计取舍

1. **事件模型只有三种**:`TextDelta`(文本增量)/`ToolCall`(完整帧,
   `arguments` 必为合法 dict)/`Usage`(流末恰好一次,provider 未上报则
   为 0)。同一 `ToolCall` dataclass 兼作历史消息元素,避免两套表示。
2. **工具调用流末按序 flush**:OpenAI 的流式 tool_calls 没有 per-call
   完成信号,统一在流末按 index 顺序产出;Anthropic 在
   `content_block_stop` 产出。provider 常规行为是「先文本后工具」,此
   路径下两后端事件序列逐字节一致(契约测试即此);病态交错(工具片段
   后又来文本)顺序可能不同,记为已知限制,WP-04 不依赖交错顺序。
3. **坏 JSON 不进 ToolCall**:模型参数非法时抛 `MalformedToolCallError`
   (携带 `tool_name`/`call_id`/`raw_arguments` 原文),保证「ToolCall
   事件的 arguments 必为 dict」这一不变量;该错误同时是实测「参数合法
   JSON 率」的统计点。上层可捕获后回灌模型纠正。
4. **错误树区分「网络问题」与「provider 拒绝」**:Network/Timeout/
   RateLimit/Server/Stream 可重试(`retryable=True`);Auth/Moderation/
   InvalidRequest/MalformedToolCall/Config 不可重试。不做内部重试——
   重试策略是 WP-04 的决策(规格排除 failover)。
5. **审核拦截检测 = 4xx/流内错误对象的特征文案匹配**(中英关键词:
   content_filter/moderation/risk/敏感/违规/审核…)+ OpenAI
   `finish_reason=content_filter` + Anthropic `stop_reason=refusal`。
   只作用于错误载荷,不碰正常内容。
6. **防 key 泄漏是行为需求不是口号**:真实 provider 的 401 文案会回显
   key(OpenAI 风格),所有引用 provider 原文的位置(HTTP 错误体、流内
   error、坏数据块摘录)一律先过 `redact_secret`;缺 key 在构造期
   fail-fast,报错只含环境变量名。密钥只走 env,构造参数不接受 key。
7. **Anthropic 差异全部收敛在 claude.py**:system 抽为顶层参数(多条
   空行拼接);连续 tool 结果与相邻同 role 消息合并(严格交替要求);
   `max_tokens` 必填 → 内部默认 8192 可覆盖,不泄漏到上层接口;
   `base_url` 按生态惯例(OpenAI 兼容含 `/v1`;Anthropic 为 API 根)。
8. **httpx 直连不引 SDK**(依赖面红线);SSE 解析共享在 base.py
   (`iter_sse_data`),忽略 `event:` 行——两家的事件类型都在 data 的
   JSON 里。OpenAI 侧默认开 `stream_options.include_usage`,个别端点不认
   可构造时 `include_usage=False` 关闭;`extra_body` 透传 provider 特有
   参数(如 temperature)。

## 踩坑

1. **本机 socks5 代理(ALL_PROXY)**:pip 走代理需 pysocks——直接
   `env -u ALL_PROXY pip install …` 绕过;httpx 运行时走 socks5 需
   `socksio`(已装入共享 .venv,仅环境工具,**非项目依赖**,Kali 上无
   此代理则不需要)。
2. **editable .pth 被置 UF_HIDDEN 导致 `import kalicode` 失败(陷阱
   HANDOVER#4 的根因)**:sandbox 写出的文件会带 macOS `UF_HIDDEN`
   旗标,Homebrew 补丁版 `site.py` 会**跳过 hidden .pth**;
   `chflags nohidden <pth>` 可修,但并发 session 重装 editable 会复发。
   裸脚本一律 `PYTHONPATH=src` 兜底(pytest 已由 pyproject 覆盖)。
3. **ruff B027**:ABC 里的空默认 `aclose` 被警告 → 改为 `@abstractmethod`
   (顺便强制未来后端实现资源释放)。E501 批量由 `ruff format` 收口,
   唯一长字符串手工断行。
4. **探针监控假象**:stdout 经 tee 块缓冲,跑了 45s 无输出以为卡住,
   实际 K3 响应很快、13 轮已全部跑完——长任务探针以后直接 `python -u`。
